# NEPÁR · Custom Studio 2.0

Mobilný štvorstupňový konfigurátor integrovaný do existujúceho statického e-shopu. Konfigurácia sa ukladá v prehliadači bez osobných údajov a dá sa zdieľať pomocou parametra `design` v URL.

## Kroky
1. Model (sveter / kardigán / top / doplnok)
2. Farebná fotografia a materiál
3. Veľkosť, strih a rozmery
4. Zhrnutie, kopírovanie, odkaz a kontaktné možnosti

## Prevádzkové obmedzenia
Toto je verejný prototyp na GitHub Pages, nie dokončený objednávkový systém. GitHub Pages nemá server, zabezpečené prihlasovanie ani databázu. Skutočné dopyty vyžadujú online backend a administrátorské účty. Nezavádzajte zákazníkov zobrazovaním AI vizualizácií ako výrobkov skladom.

## Testovanie
Otestované v Chromium pri mobilnom rozmere 390 × 844 a desktopovom 1440 × 900; otestovaný výber modelu, fotografie, rozmerov, zhrnutie a označenie ukážkových produktov.
